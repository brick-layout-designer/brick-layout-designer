Getting started

  1. Drag a part from the Parts panel onto the map, or double-click it to drop it in the middle.
  2. Ends of track snap together when they meet. Press R to turn the selected piece.
  3. Sheets keep things apart: track on one, buildings on another.
  4. The Venue button holds the hall the layout has to fit in.
  5. Ctrl+Z undoes what you just did, and Edit › Redo brings it back. Save with Ctrl+S.

Sheets

Sheets are like see-through pages stacked on the map. Put track on one, buildings on another, and scenery on a third.

Hide a sheet to see what is under it, or lock it so nothing on it moves by accident. New parts always go on the sheet that is picked.

The venue

The venue is the hall your layout goes in: its walls, doors, columns and power points. Draw it once, save it, and use it again for every layout.

With a venue under the layout, the status bar tells you if everything fits and leaves space to walk around.

Working together

If your club runs a layout server, File › Open from Server shows its layouts, venues, modules and parts in one window, and File › Save to Server puts this layout there.

Everyone working on a server layout sees each other’s changes as they happen. Editors can change the layout; viewers can only look.

Saving a copy

Save as a layout file (.bld-layout): it holds everything, including the venue, labels, modules and background picture, and opens in this app and the web app.

Export a BlueBrick map (.bbm) only for people who use the old BlueBrick program. It leaves out the venue, labels, modules and background picture.

Keyboard shortcuts

Help › Keyboard Shortcuts lists every shortcut the app has.

On a Mac, use ⌘ instead of Ctrl.
